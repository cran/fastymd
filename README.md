You can install the latest release of fastymd from
[CRAN](https://cran.r-project.org/) with:

``` {.r}
install.packages("fastymd")
```

A brief overview of fastymd is available [online](https://timtaylor.codeberg.page/fastymd/vignette.html) and in the vignette distributed with the package:

``` {.r}
vignette("fastymd", package = "fastymd")
```
